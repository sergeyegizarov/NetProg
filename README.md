# NetProg

Данный проект содержит 3 программы, реализованные через сокеты:
1) Программа-клиент для получения ответа от сервера через программу daytime. 
|----------|------------|----------------------|
| Аргумент | Значение   |        Описание      |
|          | по умолч.  |                      |
------------------------------------------------
|<IP-адрес |   Нет      |Определяет IP-адрес   |
|сервера>  |            |сервера, на который   |
|          |            |осущ. подключение     |
------------------------------------------------
2) Программа-клиент для получения ответа от сервера через программу echo. После запуска программы необходимо ввести текст, после чего сервер должен вернуть его через программу echo.
|----------|------------|----------------------|
| Аргумент | Значение   |        Описание      |
|          | по умолч.  |                      |
------------------------------------------------
|<IP-адрес |   Нет      |Определяет IP-адрес   |
|сервера>  |            |сервера, на который   |
|          |            |осущ. подключение     |
------------------------------------------------
3) Программа-сервер, к которой подключение осуществляется через localhost и порт 7777. После запуска программы, необходимо открыть новое окно терминала и использовать программу nc 
[nc localhost 7777]
После этого будет активирована сессия между клиентским окном терминала и программой, позволяющая обмениваться сообщениями.
